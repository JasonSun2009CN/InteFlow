能力边界

它做什么，它不做什么

没有用户数据可以展示，那就把边界写清楚。这两列基本决定了它是否适合你。

会做

  • 本地解析 PDF、DOCX、Markdown，还原分栏、题号、选项与答案键
  • 扫描件 OCR：macOS 用系统 Vision，其他平台用 tesseract
  • 正计时或倒计时全屏练习，交卷判分并给出分板块得分
  • 逐题分析、生词表、本地韦氏词典，导出 PDF、DOCX、xlsx

不会做

  • 不做云端同步，也没有账号系统
  • 不内置任何版权题目，示例题库只用于本地开发
  • 不会自动调用 AI，默认关闭，必须手动触发
  • 不是移动端应用，也不支持多人协作
  • 不替你总结知识点，解析要你自己写
会劝退你的问题

先看这几条，再决定装不装

一定要联网或者付 API 费用吗？

不用。导入、解析、判分、导出全是本地确定性计算。只有你主动点「AI 讲解」或者开启单词考试的 AI 评分时，才会调用你配置的服务商，并使用你自己的 key。

我的题目和解析会被上传吗？

不会。数据库在仓库的 data 目录，题目以 doc.ifmd.md 和图片的形式跟着文档存。除了你显式触发的模型调用，没有任何出网请求。

支持哪些文件？扫描件能用吗？

PDF、DOCX、Markdown 与 .ifmd.md，单个文件上限 60 MB。纯图片的扫描件走 OCR：macOS 上是系统自带的 Vision，其他平台回落到 tesseract。

不是 SAT 的题也能用吗？

可以。板块是自由标签，物理、历史、语言类题库都能导入。只要格式是「带题号、每题四个选项」，解析器就认得。

AI 讲解默认是开着的吗？

默认关闭，需要你填 key 并手动点击。设置里有 19 家服务商的目录与连通性测试，失败会静默回退到本地判分，不会卡住练习。

Windows 能用吗？怎么更新？

能，start.ps1 与 start.bat 都在仓库里。更新就是 git pull 之后重跑启动脚本，数据库结构会自动迁移，不会覆盖你的题目和解析。

安装包里有版权题目吗？

没有。仓库里的示例题库只用于本地开发，打包时会排除。你自己导入的题只存在你的电脑上。
