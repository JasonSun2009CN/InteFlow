InteFlow · themes

五个主题备选方案

五份独立的 HTML 预览页，均渲染同一个主页（侧栏 5 个 tab、统计、试卷列表、按钮与提示条）， 只有视觉语言不同，方便直接对比。纯 HTML / CSS / JavaScript，无依赖、无构建。

交互都可以点：侧栏切 tab、搜索框过滤试卷、Start 弹出提示、右上角 × 关闭提示条、 按 / 聚焦搜索、窄屏变成抽屉菜单。每页左下角的 Theme 下拉可直接换主题。

结构样式在 assets/base.css，主题 token 在 assets/themes/*.css（每个主题只有一个 :root 变量块 + 少量局部覆盖），组件与交互在 assets/mock.js。 落地到 React 版本时，把对应 :root 变量映射到 Tailwind 的 @theme / .paper-app 作用域即可。
