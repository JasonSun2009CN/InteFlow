DEMO ≠ FULL APP · what this demo leaves out
  • Four fixed questions You cannot import PDF / DOCX; the full app handles import, OCR and answer entry.
  • No backend Grading, timing and mistake/word state run in the browser; answers stay in this tab only.
  • AI Tutor is canned No model is called. The full app sends only this question’s context, and only when you click.
  • Simplified workspace Tools switch, but there is no drag-to-resize, autosave, Notebook or export.
  • Default theme only The visuals mimic Clear Blue; the full app ships 5 themes and settings.
