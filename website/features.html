01 / PRINCIPLES

两条底线。

InteFlow 不做“什么都能聊”的学习助手。它先把确定的事做对，再把可选的 AI 放在你明确按键之后。

01

LLM 不在主链路。

导入、解析、判分、复盘、导出默认都是确定性的本地计算；AI 只作为显式操作，或你主动开启的兜底出现。

  • PDF / DOCX / Markdown 默认本地转换，0 token
  • AI 识别兜底仅在开启且确定性解析失败时尝试
  • 关闭开关、无 key 或调用失败时回退本地并说明
02

数据留在本机。

题库、作答、分析、生词表都存在 data/ 下：一个 SQLite 文件，加上每套试卷的 doc.ifmd.md 与图片。默认不上传云端。

  • 没有账号，没有云端同步
  • 备份 = 复制 data/ 文件夹
  • 断网时，除了可选 AI，一切照常

02 / WORKFLOW

五步，从文件到笔记。

没有隐藏的同步步骤，也没有必须在线的工作台。每一步都能单独停下来，改完再继续。

  1. 01

    导入题库

    拖入 PDF、DOCX、.md 或 .ifmd.md，逐页报告；扫描页自动走 OCR。

    0 token
  2. 02

    补齐答案

    字母网格、多选、填空与批量粘贴；保存前可预览，保存后回写源文件。

    write-back
  3. 03

    全屏刷题

    正计时或倒计时、题号面板、键盘操作、自动判分；多选和填空都能作答。

    fullscreen
  4. 04

    逐题复盘

    2-of-4 工作台里写解析、问 AI、拖词入生词本；编辑器约 0.9 秒自动保存。

    core
  5. 05

    沉淀与导出

    Mistakes、Starred 与 Sessions 汇总练习；导出 md / docx / pdf 与词表 xlsx。

    portable

03 / CORE FEATURES

六项最常用的能力。

覆盖导入、练习、复盘、词汇与导出。完整 22 项在下方展开。

IMPORT

多格式导入

PDF、DOCX、Markdown 与 InteFlow-MD，60 MB 以内；逐页报告，可疑页面可暂停复核。

IMPORT

PDF 结构识别

双栏版面、题号、选项、答案表回填与图片抽取；识别不到选项时按填空题处理。

PRACTICE

全屏练习与判分

考试式全屏、计时、题号面板与键盘操作；多选全对、填空归一化后比较，0 token。

REVIEW

2-of-4 复盘工作台

题目、分析、AI Tutor、生词本四选二；Pages 式编辑器自动保存，布局与比例会记住。

VOCABULARY

本地词典与生词本

韦氏 92,006 条离线索引，支持自定义词典；从题目或选项拖词入表，可导出 xlsx。

OUTPUT

导出套件

复盘笔记本导出 md / docx / pdf，整套试卷导出 PDF / DOCX，词表导出 xlsx。

05 / QUESTIONS

还有疑问？

这里先回答最容易卡住的几件事。更细的规格与格式说明都在仓库文档里。

在 GitHub 提问 ↗
01只支持 SAT 吗？

不是。题目的 sec 是自由标签（rw、math、physics、history……），不是固定枚举。任何“题号 + 两个以上选项”的题库都能导入；没有识别到选项的题会按填空题处理。内置 SAT 题库只是开箱即用的示例。

02必须联网或配置 API Key 吗？

不需要。导入、解析、判分、复盘、生词本、导出都不依赖网络。只有 AI 讲解、连通性测试、以及你主动开启的单词考试 AI 评分会调用外部模型；无 key 或调用失败时会回退本地并提示。

03我的数据存在哪里？

全部在仓库的 data/：app.db 存结构化数据，docs/<id>/doc.ifmd.md 存原始题目与答案，assets/ 存图片，导出文件在 exports/。备份就复制整个目录，重置就删掉它。

04需要装哪些系统依赖？

桌面版不需要 Python / Node。从源码运行时需要 Python 3.11+ 与 Node.js 18+；PDF 导出额外需要 pango / cairo / gdk-pixbuf / harfbuzz；扫描件 OCR 可选安装 tesseract，macOS 也可用 Vision。缺哪一项，只有对应功能降级或提示。

05能用我自己的词典吗？

可以。Settings 里的 My dictionary 支持手动增删，也能导入 CSV / TSV / JSON / TXT，查词时优先于韦氏。若要英英韦氏释义，把 Eudic .eudb 放进 dictionary/，首次查词会自动建索引。版权词典文件不会随仓库分发。

06导出的笔记本包含什么？

一套试卷对应一套复盘笔记本：封面带用户名与分数，正文按题序包含所有已写解析的题目（题干、图表、你的分析）。支持 Markdown / DOCX / PDF，浏览器直接下载，同时在 data/exports/ 留一份副本。
