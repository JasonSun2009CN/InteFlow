01 / POSITION

先把边界说清楚。

InteFlow 不做“什么都能聊”的学习助手。它先把确定的事做对，再把可选的 AI 放在你明确按键之后。

RULE 01 0 TOKEN

LLM 不在主链路。

导入、解析、判分、复盘、导出默认都是确定性的本地计算；AI 只作为显式操作或你开启的兜底出现。

  • PDF / DOCX / Markdown 默认本地转换，0 token
  • AI 识别兜底：仅在你开启且确定性失败时尝试
  • AI 讲解 / 连通性测试 / 可选单词考试评分（显式）
  • 关闭开关、无 key 或调用失败时回退本地并说明

一条链路跑通，不需要任何账号。

RULE 02 LOCAL FIRST

数据默认留在这台电脑。

题库、作答、分析、生词表都存在仓库的 data/ 下：一个 SQLite 文件，加上每套试卷的 doc.ifmd.md 与图片。默认不上传云端；使用 AI 时，只会把当前题目上下文发给你配置的服务商。

  • 没有账号，没有云端同步
  • 备份 = 复制 data/ 文件夹
  • 删除 data/ 即可从零开始
  • 词典索引与导出文件也全部在本地

断网时，除了可选 AI，一切照常。

“A study tool should still work on a plane.”

断网也能导入、刷题、判分、复盘、导出。

02 / WORKFLOW

五步，从文件到笔记。

没有隐藏的同步步骤，也没有必须在线的工作台。每一步都能单独停下来，改完再继续。

06 / QUESTIONS

还有疑问？

这里先回答最容易卡住的几件事。更细的规格、数据模型与格式说明都在仓库文档里。

在 GitHub 提问 ↗
01只支持 SAT 吗？

不是。题目的 sec 是自由标签（rw、math、physics、history……），不是固定枚举。任何“题号 + 两个以上选项”的题库都能导入；没有识别到选项的题会按填空题处理。内置 SAT 题库只是开箱即用的示例。

02必须联网或配置 API Key 吗？

不需要。导入、解析、判分、复盘、生词本、导出都不依赖网络。只有 AI 讲解、连通性测试、以及你主动开启的单词考试 AI 评分会调用外部模型，并把当前题目 / 答案上下文发送给你配置的服务商；无 key 或调用失败时会回退本地并提示。

03我的数据存在哪里？

全部在仓库的 data/：app.db 存结构化数据，docs/<id>/doc.ifmd.md 存原始题目与答案，assets/ 存图片，导出文件在 exports/。备份就复制整个目录，重置就删掉它（后端会重建）。

04需要装哪些系统依赖？

基础运行只需要 Python 3.11+ 与 Node.js 18+；一键脚本会创建 .venv 并安装前后端依赖。PDF 导出额外需要 pango / cairo / gdk-pixbuf / harfbuzz；扫描件 OCR 可选安装系统 tesseract，macOS 也可用 Vision；数学公式导出可再装 MathJax 桥。缺哪一项，只有对应功能降级或提示，不会拖垮其他功能。

05能用我自己的词典吗？

可以。Settings 里的 My dictionary 支持手动增删，也能导入 CSV / TSV / JSON / TXT，查词时优先于韦氏。若要英英韦氏释义，把 Eudic .eudb 放进 dictionary/，首次查词会自动建索引。版权词典文件不会随仓库分发。

06为什么练习页不跟随主题？

这是刻意的。刷题时需要最低的视觉干扰和稳定的对比度，所以全屏练习页保持在 .app-theme 之外，使用中性的 slate / blue；复盘工作台则跟随你选择的主题。主题只改变视觉语言，不改变题目布局与交互。

07导出的笔记本包含什么？

一套试卷对应一套复盘笔记本：封面带用户名与分数，正文按题序包含所有已写解析的题目（题干、图表、你的分析）。支持 Markdown / DOCX / PDF，浏览器直接下载，同时在 data/exports/ 留一份副本。整套试卷的 PDF / DOCX 则从 Library 导出。

08应用界面是中文吗？

应用界面是英文，按钮与页面名都和 README 一致；文档提供中文与英文两版。题库内容不受语言限制，中英混合的试卷都能导入与练习。这个官网用中文介绍，只是为了让第一次接触的人更快看懂完整链路。

09可以自定义错题分析的模板吗？

可以。在 Settings → Analysis template 写一份 Markdown 模板，空的错题分析页会自动填入；已有分析绝不覆盖。 模板只是初始草稿，未改动不会保存，开始写作后才走自动保存，所以不会把空白题误算成“已写解析”而进入导出。
