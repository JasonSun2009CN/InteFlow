WHY INTEFLOW

One pipeline, three things done well.

InteFlow is not a chat assistant that does everything. It gets import, review and export right first, then puts optional AI behind a button you choose to press.

01 / CAPTURE

Question banks in

Import PDF, DOCX, Markdown or InteFlow-MD with a page-by-page report; images, answer tables and two-column layouts stay local.

See import features →
02 / REVIEW

Review question by question

Question, analysis, AI Tutor and vocabulary panes switch freely. Write your own analysis instead of only reading the answer key.

Open the demo →
03 / PORTABLE

Take understanding with you

Export notebooks as md / docx / pdf and word lists as xlsx. Back up by copying the data/ folder; no cloud lock-in.

See output features →
