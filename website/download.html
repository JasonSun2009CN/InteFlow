02 / INSTALL

首次打开，多一步。

安装包没有代码签名，所以 Gatekeeper 与 SmartScreen 会先拦一下。只需要在第一次打开时确认。

macOS · DMG

拖进 Applications，右键打开。

打开 .dmg，把 InteFlow 拖进 Applications。首次启动不要直接双击。

  1. 在 Applications 里右键 InteFlow →「打开」→ 再点「打开」。
  2. 如果仍提示「已损坏」或无法验证，在终端执行一次： xattr -dr com.apple.quarantine /Applications/InteFlow.app
  3. 之后从 Launchpad 或 Applications 正常启动。

WINDOWS · NSIS

运行 Setup，允许 SmartScreen。

双击 InteFlow-Setup-*.exe，安装器允许选择目录，不需要管理员权限。

  1. 如果 SmartScreen 出现，点「更多信息」→「仍要运行」。
  2. 按向导完成安装，从开始菜单启动 InteFlow。
  3. 未安装 Tesseract 时 OCR 会提示可选依赖，其他功能照常。

DATA & UNINSTALL

桌面版的数据默认在系统应用数据目录下的 InteFlow/data/： macOS 是 ~/Library/Application Support/InteFlow/data， Windows 是 %APPDATA%\InteFlow\data。应用菜单里有「Open data folder」。 卸载应用不会自动删除这份数据；需要彻底清理时请先备份，再手动删除。

03 / FROM SOURCE

不想等安装包？
从源码启动。

需要 Python 3.11+ 与 Node 18+。start.sh 首次运行会自动建 .venv、安装前后端依赖；之后直接启动。Windows 用 start.ps1 或双击 start.bat。
