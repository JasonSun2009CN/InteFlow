02 / INSTALL

First launch takes one extra step.

The builds are not code-signed, so Gatekeeper and SmartScreen will ask once. After that, open normally.

macOS · DMG

Drag to Applications, then right-click Open.

Open the .dmg and drag InteFlow into Applications. Do not double-click it the first time.

  1. In Applications, right-click InteFlow → Open → Open again.
  2. If macOS still says the app is damaged or cannot be verified, run once in Terminal: xattr -dr com.apple.quarantine /Applications/InteFlow.app
  3. After that, launch it normally from Launchpad or Applications.

WINDOWS · NSIS

Run Setup and allow SmartScreen.

Double-click InteFlow-Setup-*.exe. The installer lets you choose a folder and does not need admin rights.

  1. If SmartScreen appears, choose More info → Run anyway.
  2. Finish the wizard and launch InteFlow from the Start menu.
  3. Without Tesseract, OCR shows an optional-dependency note; everything else works.

DATA & UNINSTALL

Desktop data lives under the app-data folder in InteFlow/data/: on macOS ~/Library/Application Support/InteFlow/data, on Windows %APPDATA%\InteFlow\data. A new download starts empty — no sample exams, sessions or vocabulary are preloaded. The app menu has “Open data folder”, and File → “Reset local data…” restores a fresh install. Uninstalling does not delete that data; back it up first, then remove it manually if you want a clean slate.

03 / FROM SOURCE

For developers:
run from source.

This downloads source code, not the desktop installer. The installers above are the recommended way to use InteFlow. This section is for development: you need Python 3.11+ and Node 18+. start.sh creates a .venv and installs frontend/backend dependencies on first run; later runs start directly. On Windows use start.ps1 or double-click start.bat.

Download source ZIP (developers) ↓ GitHub repository ↗
TERMINAL 2 COMMANDS
$ git clone https://github.com/JasonSun2009CN/InteFlow.git
$ cd InteFlow && ./start.sh

On Windows use .\start.ps1 or double-click start.bat. The first run needs network access for dependencies; later runs work offline.
