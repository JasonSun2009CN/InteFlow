01 / PRINCIPLES

Two ground rules.

InteFlow is not a study assistant that can chat about anything. It gets the certain things right first, then puts optional AI behind a key you explicitly press.

01

The LLM is not on the main path.

Import, parsing, grading, review and export are deterministic local computation by default; AI appears only as an explicit action, or as a fallback you have switched on.

  • PDF / DOCX / Markdown convert locally by default, 0 tokens
  • AI recognition fallback only when enabled and deterministic parsing fails
  • No switch, no key or a failed call → local fallback with a clear message
02

Your data stays on this computer.

Question banks, answers, analysis and vocabulary live under data/: one SQLite file, plus each paper's doc.ifmd.md and images. Nothing is uploaded to the cloud by default.

  • No accounts, no cloud sync
  • Backup = copy the data/ folder
  • Offline, everything works as usual — except the optional AI

02 / WORKFLOW

Five steps, from file to notes.

No hidden sync step, and no workbench that has to be online. Every step can stop on its own — change what you need, then carry on.

  1. 01

    Import a question bank

    Drag in PDF, DOCX, .md or .ifmd.md with a page-by-page report; scanned pages go through OCR.

    0 token
  2. 02

    Complete the answer key

    Letter grid, multi-select, fill-ins and bulk paste; preview before saving, then write back to the source.

    write-back
  3. 03

    Practise in full screen

    Count-up or countdown timer, question panel, keyboard control and automatic grading; multi-select and fill-in included.

    fullscreen
  4. 04

    Review question by question

    Write analysis, ask AI and drag words into vocabulary in the 2-of-4 workspace; autosave in about 0.9 seconds.

    core
  5. 05

    Distil and export

    Mistakes, Starred and Sessions gather your practice; export md / docx / pdf and word lists as xlsx.

    portable

05 / QUESTIONS

Still have questions?

Here are the answers to the things people trip over first. More detailed specs and format documentation live in the repo docs.

Ask on GitHub ↗
01Does it only support SAT?

No. A question's sec is a free-form label (rw, math, physics, history…), not a fixed enum. Any bank made of "question number + two or more options" can be imported; items where no options are detected are treated as fill-ins. The built-in SAT bank is just an out-of-the-box example.

02Do I need to be online or configure an API key?

No. Import, parsing, grading, review, vocabulary and export don't depend on a network. Only AI explanations, connectivity tests, and word-exam AI grading that you turn on yourself call an external model; with no key or a failed call it falls back to local and tells you.

03Where is my data stored?

All under data/: app.db holds structured data, docs/<id>/doc.ifmd.md holds the original questions and answers, assets/ holds images, and exports land in exports/. To back up, copy the whole directory; to reset, delete it.

04Which system dependencies do I need?

The desktop app needs no Python or Node. Running from source needs Python 3.11+ and Node.js 18+; PDF export additionally needs pango / cairo / gdk-pixbuf / harfbuzz; scanned-page OCR can optionally use tesseract, and macOS can also use Vision. When something is missing, only that feature degrades or warns.

05Can I use my own dictionary?

Yes. My dictionary in Settings supports manual edits and imports from CSV / TSV / JSON / TXT, and takes priority over Merriam-Webster. For English-to-English Merriam-Webster definitions, put an Eudic .eudb into dictionary/ and the index is built automatically on first lookup. Copyrighted dictionary files are not distributed with the repo.

06What does the exported notebook contain?

One review notebook per paper: a cover with the user name and score, then every question with written analysis in question order (stem, figures, your analysis). Markdown / DOCX / PDF, downloaded straight from the browser with a copy left in data/exports/.
